### Descrição

Este projeto consiste no desenvolvimento de um banco de dados relacional para gerenciamento de uma agência de viagens.

O sistema permite o cadastro de clientes, companhias aéreas, aeroportos, aeronaves, agentes de viagem, voos, reservas e pagamentos, garantindo integridade referencial e organização das informações por meio de um modelo relacional normalizado.
